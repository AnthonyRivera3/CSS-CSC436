Getting the repo

Full instructions live in the README. The short version, from your terminal: 

# 1. clone it
git clone https://github.com/<your-org>/css-fundamentals.git
cd css-fundamentals

# 2. open it — there is no build step, no npm install, nothing to compile
open index.html          # macOS
start index.html         # Windows
Better than double-clicking: open the folder in VS Code, install the Live Server extension, then right-click index.html → Open with Live Server. You get automatic reload on save, and the exercise pages behave exactly as they will on a real server.

How a page in this repo is put together

Every page loads two stylesheets, in this order: 

<link rel="stylesheet" href="assets/css/base.css">        ← components + tokens
<link rel="stylesheet" href="assets/css/theme-persona.css"> ← redefines the tokens

base.css defines the reset, the design tokens, and every component (.card, .btn, .nav…). A theme file re-declares those tokens and adds a handful of signature flourishes. Nothing in a theme file rewrites a component from scratch.

That is why the three lessons look nothing alike while sharing about 90% of their CSS — and it is the single most useful habit in this course.

The house rules

  • Type it, don't paste it. Muscle memory is the point of a walk-along.
  • Break it on purpose. Every property you learn, change it to a wrong value once and look at what happens.
  • Inspect everything. F12 → Elements → Styles. If you cannot see why a rule is winning, you cannot debug it.
  • No !important without saying out loud why. Usually there is a specificity fix instead.
  • Commit at the end of every session so you have a history of your own progress.

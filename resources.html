Where to get fonts

The single most effective thing a beginner can do to make a page look designed is to stop using the default font. Start at the top of this list.

Icons, while we're here

Lucide, Phosphor, Tabler, Heroicons. All free, all SVG, all styleable with currentColor.

Licences are not optional. Most free fonts use the SIL Open Font License: use it anywhere, including commercially, but you may not sell the font itself and any modified version must keep the licence. "Free for personal use" means not for your client work. Check before you ship, not after.

Actually putting a font on the page

Option A — the hosted link (what this repo does)

Paste the <link> from the font site into your <head>, above your own stylesheet:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Archivo+Black&display=swap" rel="stylesheet">

Then use it, always with fallbacks:

:root { --font-display: "Archivo Black", Impact, sans-serif; }
  • preconnect opens the network connection early — worth roughly 100ms.
  • display=swap shows your fallback immediately and swaps when the webfont arrives. Without it the text is invisible while the font loads.
  • Request only the weights you use. wght@400;700, not the whole family. Every extra weight is another file.

Option B — self-hosting

Faster, private, and works offline. Download the .woff2 files into assets/fonts/ and declare them yourself:

@font-face {
  font-family: "Archivo Black";
  src: url("../fonts/archivo-black.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;
}

/* A variable font: one file covers the whole weight range. */
@font-face {
  font-family: "Inter var";
  src: url("../fonts/inter-var.woff2") format("woff2-variations");
  font-weight: 100 900;   /* a range, not a number */
  font-display: swap;
}
Ship woff2 and nothing else. Every browser in current use supports it, and it is the smallest format. ttf and otf on the web are wasted bytes.

Swapping the font in this repo

Change two things and the whole page follows, because every component reads the token rather than naming a font directly: 

/* 1. the <link> in the page's <head> */
/* 2. one line in the theme file: */
:root { --font-display: "Your New Font", Georgia, serif; }

Testing a library inside this repo, safely

Drop it into a low cascade layer. Your own CSS then wins every conflict without a single !important: 

/* at the very top of your stylesheet */
@layer vendor, base, components, theme, utilities;

@import url("https://cdn.jsdelivr.net/npm/@picocss/pico@2/css/pico.min.css") layer(vendor);

@layer base {
  /* your rules beat everything in vendor, no matter how specific they are */
}
Two rules for third-party CSS in this course: never add a library to solve something you have not tried to solve yourself first, and never add one you have not opened and read.

Generators & copy-paste snippets

For when you know what you want and don't want to hand-compute a cubic-bezier. Paste the output, then read it until you understand it.

Backgrounds

MagicPattern, Haikei (SVG blobs and waves), CSS Gradient, Comeau's gradient generator (interpolates in better colour spaces).

Shadows & depth

Smooth Shadow for layered, realistic shadows. Neumorphism.io if you must.

Shapes

Clippy for clip-path polygons — this is how the Persona slashes and the BG3 dice were made. css-generators.com for far more advanced shapes.

Motion

cubic-bezier.com, easings.net, Animate.css, CSS Loaders — a few hundred spinners, single-element.

Whole components

Uiverse.io (community CSS components), HyperUI (free Tailwind blocks), Flowbite.

Colour

Coolors, oklch.com (the modern colour picker), Happy Hues (palettes shown in context), WebAIM Contrast Checker.

Tools on your machine

Browser DevTools

Your most important tool by an enormous margin. Learn the Styles pane, the flex/grid overlays, the Computed tab, and device emulation. F12 or ⌥⌘I.

VS Code + Live Server

Auto-reload on save. Add Prettier for formatting and Stylelint for catching mistakes as you type.

Lighthouse & axe

Built into Chrome DevTools. Run Lighthouse for performance and axe DevTools or WAVE for accessibility. Both find real bugs in seconds.

Sandboxes

CodePen for a quick experiment, StackBlitz or CodeSandbox for a whole project. Share a pen when you ask me a question.

Responsive testing

Responsively and Polypane show many viewports at once. Or just drag your window — do that constantly.

Build tools, later

Lightning CSS and PostCSS transpile modern syntax for older browsers. You do not need them for this course — that is deliberate.
